# Analytics Dashboard UI Design & Figma Design System

UI/UX Design Internship project for **Devnexes Digital Solutions**.
This project delivers a complete Figma design system and a responsive analytics dashboard, including user research, a component library, high-fidelity screens, and an interactive prototype.

## Project overview

**Domain track:** UI/UX Design
**Assigned project:** Analytics Dashboard UI Design & Figma Design System
**Duration:** 1 month (4 weeks)
**Tools used:** Figma (Auto-Layout, Component Variants, Variables), FigJam

## What's included

### 1. User research & wireframing
- Two user personas (business manager and data analyst) covering the primary user types
- A step-by-step user flow diagram from login to data export
- A low-fidelity wireframe of the full dashboard layout (navbar, sidebar, KPI cards, charts)

### 2. Design system
- **Color variables** — separate Light and Dark color collections (background, surface, primary, text-main, text-muted)
- **Typography styles** — five reusable text styles: Heading/Large, Heading/Medium, Body/Regular, Body/Small, Number/Large
- **Component** — a reusable Button/Primary component

### 3. High-fidelity screens
- Full desktop dashboard screen (1440px) with navbar, sidebar navigation, KPI cards, and chart sections
- Responsive mobile dashboard screen with a stacked single-column layout
- Consistent styling applied throughout: white surfaces, rounded corners, subtle shadows, and the design system's color palette

### 4. Interactive prototype
- Clickable "Export" button connecting the mobile dashboard to the desktop dashboard screen
- Demonstrates a working navigation flow between screens
